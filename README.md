# uniquemalls

Mall recharge web application with admin tools and payment workflows.

## Description

`uniquemalls` is a PHP-based recharge web application. It includes customer-facing flows, department admin tools, promotion and recharge workflows, cron-style handlers, and asset pages for mall operations.

## Installation

1. Place the project in your local web server document root.
2. Import the database schema used by the project's MySQL database.
3. Update database connection settings in `connection.php`.
4. Ensure required PHP and MySQL versions are enabled on the server.

## Usage

- Access `index.php` for the main application entry point.
- Use admin login pages for department-specific management workflows.
- Review `README.md` and the root PHP pages for runtime guidance specific to your deployment.
